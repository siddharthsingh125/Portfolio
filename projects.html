Market / Platform Education / Training
Devices Mobile & Desktop
Primary Goal Improve user experience and content navigation

Challenge

The Dekra PLP page had multiple content sections displayed one after another, making the page long and requiring users to scroll through a large amount of content.

  • Implemented the layout for both desktop and mobile devices

The main goal was to make the Dekra PLP easier to navigate by reducing page length and presenting the existing content in a cleaner, more organized layout.
